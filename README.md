# پنل ساخت سایت و ربات

لینک پنل (بعد از فعال‌سازی GitHub Pages):
**https://r82146777-art.github.io/site-bot-builder-panel/**

## چطور GitHub Pages را فعال کنید؟
1. بروید به Settings مخزن
2. از منوی سمت چپ Pages را انتخاب کنید
3. Source را روی `Deploy from a branch` بگذارید
4. Branch را `main` و پوشه را `/ (root)` انتخاب کنید
5. Save کنید

بعد از ۱–۲ دقیقه لینک بالا کار می‌کند.

## قابلیت‌ها

### صفحه ورود
با یک کلیک وارد پنل می‌شوید.

### ساخت سایت
- کد HTML را وارد کنید
- دکمه «ساخت سایت و دریافت لینک» را بزنید
- سایت فوراً در تب جدید باز می‌شود
- لینک در لیست ظاهر می‌شود و می‌توانید کپی کنید یا دوباره باز کنید

### ساخت ربات (تلگرام / روبیکا / بله)
- توکن + آیدی‌های مجاز + کد منطق را وارد کنید
- کد آماده پایتون تولید می‌شود
- دکمه دانلود `bot.py`
- شبیه‌ساز تست داخل خود پنل
- دستورالعمل خیلی ساده برای اجرا روی کامپیوتر یا سرور رایگان

> توجه: مرورگر نمی‌تواند ربات را ۲۴ ساعته روشن نگه دارد. به همین خاطر کد کامل آماده دانلود می‌شود تا با یک دستور اجرا شود.
