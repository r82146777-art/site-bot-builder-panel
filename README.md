# پنل ساخت سایت و ربات

یک پنل ساده و زیبا برای ساخت و مدیریت:

- **ربات‌های تلگرام، روبیکا و بله**
- **سایت‌های شخصی‌سازی‌شده**

## ویژگی‌ها

### بخش ساخت ربات
- انتخاب پلتفرم (تلگرام / روبیکا / بله)
- وارد کردن توکن ربات
- تعیین کاربران مجاز با آیدی عددی
- کادر کد برای منطق ربات
- دکمه ذخیره و استارت
- لیست ربات‌های فعال با امکان ویرایش و حذف

### بخش ساخت سایت
- تعیین مالک (آیدی، شماره یا ایمیل) برای دسترسی مدیریت
- کادر کد سایت (HTML/CSS/JS)
- دکمه ساخت سایت
- لیست سایت‌های ساخته‌شده با ویرایش و حذف

## نحوه استفاده

1. فایل‌ها را در GitHub Pages فعال کنید یا به صورت لوکال باز کنید.
2. داده‌ها در `localStorage` مرورگر ذخیره می‌شوند.

> **توجه:** این پنل یک رابط کاربری (Frontend) است و اجرای واقعی ربات یا هاستینگ سایت نیاز به بک‌اند دارد.
